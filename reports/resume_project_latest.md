# Travel Agentic RL｜简历项目表述

- 完成旅行 Agent 的数据构建、SFT 冷启动、GRPO 训练与奖励设计，建立八工具冻结 replay 和模型评测流程。
- 在冻结的 80 条内部任务上，GRPO-v1 结构成功率达 **85.0%（68/80）**，较 SFT-v2 提升 **16.25 个百分点**。
- 采用 GPT、Gemini 双 Judge，按 **30% 路径质量＋70% 终答质量**进行 A/B 双向评审；GRPO-v1 对 SFT-v2 的胜/平/负分别为 **55/9/16、57/15/8**，支持选择 GRPO-v1 作为内部交付模型。

口径：结构成功率不等于真实任务成功率；双 Judge 汇总含用户授权的批量补评，不宣称全部为独立盲评。完整方法、置信区间、协议限制及历史结果见 [最终报告](final_metrics_report_063.md)。本页仅整理已完成且可解释的工作，不新增实验任务，不将胜平折半偏好分当作直接胜率。
